Click the buttons below to test your backend endpoints and see the JSON responses.

🔧 Base URL

Default is the hosted backend. Override via ?base= query param.

1️⃣ GET /jobseeker/ (All Data)

Fetches all JobSeeker data including profile, jobs, stats, etc.

2️⃣ GET /jobseeker/application (Applications)

Fetches all job applications.

3️⃣ PATCH /jobseeker/update (Update Data)

Example PATCH request (will try to update with test data).

4️⃣ GET /jobseeker/job (Jobs)

Fetches all jobs. Shows count and first 3 items.

5️⃣ GET /jobseeker/candidate (Candidates)

Fetches all candidates. Shows count and first 2 items.

6️⃣ GET /users/search (Search Users)

Searches users by name using either ?q= or ?search=.
